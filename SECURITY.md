# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Email **lb.guitton@gmail.com** with a description of the problem, the affected
version, and steps to reproduce it. You will get an acknowledgement as soon as
possible, and we will keep you informed while we investigate and prepare a fix.

## Supported versions

Only the latest release of GitWand (desktop app, `@gitwand/core`,
`@gitwand/cli`, `@gitwand/mcp`) receives security fixes.

## Automated scanning

GitWand is enrolled in [OSS Scanner](https://github.com/anthropics/oss-scanner).
Reports it produces are sent to the address above.
